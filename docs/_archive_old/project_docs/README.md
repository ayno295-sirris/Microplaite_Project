# Workspace Documentation

Shared documentation for the Microplaite workspace lives here.

## Index

- `architecture.md`: current system architecture.
- `architecture/workspace_structure.md`: repository layout and project
  separation.
- `hardware.md`: bench hardware notes.
- `communication_protocols.md`: Raspberry Pi to ESP32 protocol notes.
- `milestones.md`: implementation roadmap.
- `codex_rules.md`: legacy Codex rules retained for context.
- `codex/workspace_context.md`: compact context for future Codex sessions.

ESP32-specific documentation lives under `firmware/esp32_platformio/docs/`.
The heater hardware and control reference is
`firmware/esp32_platformio/docs/hardware/heater_control_system.md`.
